# LEE JUNYOUNG · 84A

전남대학교 건축학부(공학전공) 이준영의 개인 홈페이지입니다.

**주소: https://junyeong1810.github.io**

## 컨셉

홈 화면은 아파트 단위세대 평면도(84A)입니다. 평면도의 방 하나하나가 메뉴여서, 방을 누르면 그 방에 배정된 상세 페이지로 바로 이동합니다. 사이트 전체를 한 세트의 설계도서처럼 구성했습니다. 홈은 도면번호 A-101, 상세 페이지는 A-201~A-209입니다. 홈에는 도면 테두리, 방위표, 축척 막대, 도면 목록, 표제란을 넣었고, 상세 페이지 머리말의 도면번호와 꼬리말의 작은 표제란으로 홈과 이어지게 했습니다.

## 사용 기술

- **HTML · CSS · JavaScript**: 빌드 도구나 프레임워크 없이 만든 정적 사이트입니다. `index.html`을 더블클릭해서 열어도 모든 기능이 동작합니다.
- **GitHub Pages**: `main` 브랜치 루트를 그대로 배포합니다.
- **DXF → SVG 변환 스크립트** (`scripts/dxf_to_svg.py`, Python · ezdxf · shapely):
  - 원본 CAD 도면(DXF)에서 벽체·창호·문을 뽑아, 단순화한 평면도 SVG를 만듭니다.
  - 방 영역과 면적(㎡)도 이 스크립트가 계산합니다.
  - 결과 SVG는 `index.html`에 인라인으로 들어갑니다.
  - 원본 도면은 저장소에 올리지 않았습니다.
- **SVG 그래픽**: 평면도의 그려지는 효과·방 강조, 이력 공정표(오늘선, 일시중지를 뺀 전체 공정률 자동 계산)를 SVG와 순수 JavaScript로 만들었습니다.
